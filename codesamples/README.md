# Statistics Code Samples

Code Samples in R and Python, reflecting some of my programming work for acadmeic and research projects as a Master's student.

- [Geo Visuals](https://github.com/jgkissell/data-science-portfolio/blob/main/codesamples/Geo_Visuals.ipynb): A full-length, documented Jupyter notebook written to process data, perform Wavelet decomposition, and calculate correlations and partial correlations between wavelet coefficients at varying decomposition scales. Features creation of tables and visualizations which were included in an academic manuscript.
- [Malarial Unit](https://github.com/jgkissell/data-science-portfolio/blob/main/codesamples/MalarialUnit2.Rmd): R code to fit and evaluate Bayesian hierarchical spatio-temporal model with Conditional Autoregressive priors. Features geospatial data processing with shapefiles and evaluation of multivariate models with spatio-temporal predictors and additional covariates.
- [Final Data Analysis 2](https://github.com/jgkissell/data-science-portfolio/blob/main/codesamples/FinalDataAnalysis2.Rmd): R code to calculate impulse response functions and forecast error variance decomposition to multivariate economic autoregressive time series. Features advanced time series modeling and visualizations.
