# Statistics Code Samples

Code Samples in R and Python, reflecting some of my programming work for acadmeic and research projects as a Master's student.

- [Wavelets Research](https://github.com/jgkissell/data-science-portfolio/blob/main/codesamples/Geo_Visuals.ipynb): Features creation of tables and visualizations which were included in an academic manuscript. Python Jupyter notebook written to process data, perform Wavelet decomposition, and calculate correlations and partial correlations between wavelet coefficients at varying decomposition scales.
- [Bayes Spatiotemporal](https://github.com/jgkissell/data-science-portfolio/blob/main/codesamples/MalarialUnit2.Rmd): R code to fit and evaluate Bayesian hierarchical spatio-temporal model with Conditional Autoregressive priors. Features geospatial data processing with shapefiles and evaluation of multivariate models with spatio-temporal predictors and additional covariates.
- [VAR Impulse Response](https://github.com/jgkissell/data-science-portfolio/blob/main/codesamples/FinalDataAnalysis2.Rmd): R code to calculate impulse response functions and forecast error variance decomposition to multivariate economic autoregressive time series. Features advanced time series modeling and visualizations.
